## B dan C. Tampilan, aksesibilitas, dan keamanan (40%)

| Butir | Hasil | Yang belum diverifikasi |
|---|---|---|
| B: Responsif | Tata letak responsif sudah ada; rute PDF kini mendukung tampilan PDF langsung dan permintaan parsial HTTP. | Uji tampilan dan zoom di perangkat ponsel/tablet. |
| B: Aksesibilitas | Kontras tinggi, pembesaran teks, fokus/tautan lewati konten, dan pembaca teks tersedia. | Uji keyboard dan pembaca layar sungguhan; pembaca teks bawaan tidak menggantikan uji ini. |
| B: Navigasi dan Pencarian | Navigasi menandai halaman aktif, pencarian publik tersedia, URL eviden ditempatkan di halaman relevan. | Uji pengguna mencari dokumen dari beranda pada rilis hosting. |
| C: Keamanan | TLS subdomain tes lolos validasi sertifikat saat dicek. Kode MFA TOTP admin ditambahkan; uji membuktikan kata sandi saja ditolak untuk admin terdaftar dan kode tidak bisa dipakai ulang. | Pasang migrasi aditif MFA, daftarkan akun, lalu wajibkan MFA. Catat versi PHP/Laravel dari hosting. |
| C: Kecepatan | Respons HTML beranda tes sekitar 0,98 detik pada satu pengukuran HTTP. | Bukan waktu muat halaman lengkap. Ukur ulang setelah deploy dengan browser/Lighthouse pada profil penilaian. |
| C: Tautan | Uji lokal tanpa login: 30/30 PDF arsip memberi `206 application/pdf` dengan isi PDF, dan impor ulang tidak membuat duplikat. | Di hosting sebelum pemasangan, URL contoh PDF WordPress di subdomain dan `/hasil-survei-pelayanan` masih 404. Uji ulang tautan PDF lokal setelah impor. |
